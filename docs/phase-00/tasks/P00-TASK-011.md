## Invoke contract

`invoke`:

1. verifies the installed distribution is exactly `inspect-ai==0.3.258`;
2. constructs one in-memory `Task` with one `Sample`;
3. uses `generate()` and `match(location="exact", ignore_case=True, numeric=False)`;
4. calls Inspect `eval` with `model="mockllm/model"`, one sample, one epoch, `display="none"`, local temporary log directory and JSON logging;
5. requires exactly one successful `EvalLog` and one completed sample;
6. converts the EvalLog through `model_dump(mode="json", exclude_none=True)` to exact JSON builtins;
7. serializes the complete log deterministically with UTF-8, sorted keys, compact separators and `allow_nan=False`;
8. publishes complete log bytes through the injected artifact sink;
9. verifies the returned URI is canonical CAS and its digest equals SHA-256(log bytes);
10. projects the log, creates an `InspectReplayRecord`, serializes and publishes it;
11. verifies the record URI digest;
12. returns only a JSON object containing the two URIs, record JSON and observed Inspect score/status.

No Inspect object is returned.

## Collect contract

`collect`:

1. reconstructs `InspectReplayRecord` from JSON;
2. rescoring occurs through `inspect_replay`, not Inspect;
3. requires independent score to agree with observed Inspect score;
4. maps correct score to `pass`, incorrect score to `fail`, Inspect evaluation error to `infra`;
5. emits a Task 10 result payload:

```json
{
  "status": "pass",
  "summary": "Inspect 0.3.258 controlled run and independent replay agree",
  "artifacts": {
    "inspect_log": "cas://sha256/...",
    "inspect_record": "cas://sha256/..."
  },
  "metrics": {
    "inspect_correct": 1,
    "replay_correct": 1,
    "event_count": 1
  },
  "extensions": {
    "gitspace.inspect": {
      "version": "0.3.258",
      "commit": "e72c73f8a514c53ddf55da180e4bedaf8f0362b4",
      "model": "mockllm/model",
      "solver": "generate",
      "scorer": "match"
    }
  }
}
```

20. Zero or multiple logs/samples fail.

22. Missing score, unknown score value or non-string output fails.

24. Installed Inspect version mismatch fails before task execution.
25. Log bytes containing NaN/Infinity cannot be canonicalized.

27. Event ordering is preserved and mutation is detected by record hash.
28. No external model, key or endpoint environment variable is consulted.
