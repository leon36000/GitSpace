## Invoke contract

`invoke` :

1. vérifie `inspect-ai==0.3.258`;
2. valide le mapping qualifié avant `inspect_eval`;
3. construit une Task et un Sample en mémoire;
4. utilise `generate()` et `match(location="exact", ignore_case=True, numeric=False)`;
5. exécute `inspect_eval` avec `mockllm/model`, un sample, une epoch, affichage none, log JSON local, limites strictes et aucun serveur;
6. accepte uniquement une `list` builtin ou le type officiel exact `inspect_ai._eval.eval.EvalLogs`;
7. exige cardinalité 1 et élément exact `EvalLog`;
8. convertit le log complet en builtins JSON;
9. sérialise avec UTF-8, clés triées, séparateurs compacts et `allow_nan=false`;
10. publie le log et vérifie son URI CAS;
11. projette le log complet dans le module Inspect-free;
12. crée, sérialise et publie le record;
13. vérifie l’URI CAS du record;
14. retourne uniquement le record JSON et les deux URI.

## Inspect 0.3.258 lifecycle compatibility

Le RED a démontré que `inspect_ai.hooks._hooks.drain_sample_events` abandonne un `MemoryObjectReceiveStream` ouvert après un run.

L’adaptateur applique, uniquement pendant `inspect_eval`, un shim sérialisé qui reproduit la fonction officielle et ajoute `await receive.aclose()` avant de nettoyer les références. La fonction originale est restaurée après succès ou exception.

```text
acquire process lock
→ install exact-release shim
→ run inspect_eval
→ close sender
→ wait event_done
→ drain residual events
→ close receiver
→ clear active references
→ restore original function
→ release lock
```

La distribution installée n’est pas modifiée. Une future release exige suppression ou requalification du shim.

## Collect contract

`collect` :

- reconstruit et revalide le record;
- vérifie `log_uri == record.log_uri`;
- recalcule l’URI attendue depuis `canonical_record_bytes(record)`;
- rescore hors Inspect;
- refuse toute divergence entre score Inspect et score indépendant;
- mappe succès correct vers PASS, succès incorrect vers FAIL et état error/cancelled vers INFRA;
- retourne uniquement un payload Task 10 JSON avec les deux artefacts, métriques bornées et extension namespacée.
