## Toolchain decision

```yaml

python: 3.12.13
uv: 0.12.0
```

Justification :

- Rust 1.97.1 est le point release stable officiel vérifié le 2026-08-13;
- Harbor requiert Python `>=3.12`;
- Inspect Evals supporte au minimum Python 3.11 et sa documentation privilégie encore 3.11/3.12 pour la compatibilité;
- Python 3.12.13 contient les correctifs de sécurité courants de la série 3.12, même si la distribution officielle est désormais source-only;
- uv 0.12.0 est la release stable qualifiée le 2026-08-13.
