# P00-TASK-010 — SDK Python d’adaptateur provider-neutral

## Goal

Construire une frontière Python locale, versionnée et provider-neutral entre l’Evaluation IR souverain de GitSpace et les frameworks externes, sans laisser une classe, une exception, une valeur non JSON, une perte sémantique ou une référence d’artefact non canonique contaminer le noyau.

## Success criteria

```text
EvalTaskSpec + AgentConfiguration
→ validation locale Draft 2020-12 avant accès à l’adaptateur
→ copie JSON stricte
→ prepare + snapshot canonique exact
→ invoke
→ collect
→ AdapterResult JSON-only normalisé
```

La même entrée et le même adaptateur factice produisent une sérialisation déterministe. Toute divergence sémantique ou violation de frontière échoue avant l’invocation externe ou devient un résultat borné explicitement classifié.

## Non-scope

- adaptateur concret Inspect, Harbor, Terminal-Bench, SWE-bench ou AgentDojo;
- appel de modèle, réseau, téléchargement, conteneur, VM ou sandbox;
- runner, CAS, journal ou verdict engine;
- modification des huit schémas Evaluation IR v1;
- protocole distribué, base de données, Temporal ou Neon;
- chiffrement, signature, authentification du contenu externe ou redaction complète des secrets;
- canon, RAGLite ou Task 11 avant preuve post-merge.

## Applicable decisions and invariants

- Architecture C et C0;
- Evaluation IR GitSpace reste souverain;
- frameworks externes = adaptateurs remplaçables;
- toute donnée externe est `UNTRUSTED_DATA`;
- validation locale Draft 2020-12 avant le premier accès à `descriptor`, `prepare`, `invoke` ou `collect`;
- aucune résolution réseau de schéma;
- seuls les builtins JSON exacts traversent la frontière;
- chaque arbre accepté est copié en profondeur;
- extensions namespacées seulement;
- artefacts = références CAS canoniques seulement;
- aucun statut, score ou exception externe ne devient une preuve GitSpace;
- faux `DONE = 0`.

### Descriptor

```python
@dataclass(frozen=True, slots=True)
class AdapterDescriptor:
    name: str
    version: str
    protocol_version: int
    implementation_digest: str

    @property
    def identity(self) -> str: ...
```

- instance exacte de `AdapterDescriptor`, pas une sous-classe;
- `name` ASCII lowercase `^[a-z0-9]+(?:[._-][a-z0-9]+)*$`;
- `version` ASCII imprimable non vide;
- `protocol_version` = entier exact `1`, pas bool;
- digest `sha256:` lowercase sur 64 hex;
- identité déterministe contenant les quatre champs.

### Request

```python
@dataclass(frozen=True, slots=True)
class AdapterRequest:
    task: dict[str, JsonValue]
    agent: dict[str, JsonValue]
    seed: int
    extensions: dict[str, JsonValue]
```

Objet canonique produit :

```json
{
  "version": 1,
  "task": {},
  "agent": {},
  "seed": 0,
  "extensions": {}
}
```

- `task` valide `urn:gitspace:schema:v1:eval-task-spec`;
- `agent` valide `urn:gitspace:schema:v1:agent-configuration`;
- les huit schémas sont enregistrés localement;
- aucune propriété de l’adaptateur n’est consultée avant ces validations.

### Adapter protocol

```python
descriptor: AdapterDescriptor

def prepare(self, request: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
def invoke(self, prepared: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
def collect(self, raw: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
```

`prepare` retourne exactement :

```json
{
  "canonical_request": {},
  "framework_request": {},
  "extensions": {}
}
```

`canonical_request` doit être exactement égal à la requête validée après normalisation. Une modification, omission ou clé supplémentaire lève `SemanticLossError` ou `AdapterContractError` avant `invoke`.

`collect` retourne exactement :

```json
{
  "status": "pass|fail|timeout|policy|infra",
  "summary": "texte borné",
  "artifacts": {"name": "cas://sha256/<64 lowercase hex>"},
  "metrics": {"name": 0},
  "extensions": {}
}
```

### Result

```python
class AdapterStatus(str, Enum):
    PASS = "pass"
    FAIL = "fail"
    TIMEOUT = "timeout"
    POLICY = "policy"
    INFRA = "infra"

@dataclass(frozen=True, slots=True)
class AdapterResult:
    adapter_identity: str
    status: AdapterStatus
    summary: str
    artifacts: dict[str, str]
    metrics: dict[str, int | float]
    extensions: dict[str, JsonValue]

    def to_json(self) -> dict[str, JsonValue]: ...
```

Le constructeur public applique les mêmes règles que `execute_adapter`; il ne constitue pas une voie de contournement.

## Strict JSON boundary

Valeurs permises, avec types builtin exacts :

```text
None | bool | str Unicode scalar-only | safe int |
finite float excluding -0.0 | list | dict[str, JsonValue]
```

Rejets obligatoires :

- sous-classes de `dict`, `list`, `str`, `int` ou `float`;
- bytes, tuple, set, dataclass, enum non converti, iterator ou classe arbitraire;
- clé qui n’est pas un `str` exact;
- NaN, ±Infinity et zéro négatif;
- entier hors `[-9007199254740991, 9007199254740991]`;
- surrogate Unicode isolé;
- cycle;
- profondeur supérieure à 64;
- clé core inconnue dans prepared/result;
- toute stringification ou représentation d’un objet externe avant validation de son type.

## Namespaced extensions

Les clés top-level des extensions suivent :

```regex
^[a-z0-9]+(?:[.-][a-z0-9-]+)+$
```

Une clé non namespacée telle que `debug` est refusée dans request, prepared et result.

## Runtime normalization

- payload normal : statut collecté strictement parmi cinq valeurs;
- `AdapterTimeout` dans prepare/invoke/collect : TIMEOUT;
- `AdapterPolicyViolation` : POLICY;
- autre `Exception` : INFRA;
- le type d’exception est enregistré sans faire confiance à son message;
- `__str__` hostile produit un fallback déterministe;
- résumé single-line, caractères de contrôle supprimés, maximum 512 points de code;
- erreurs de schéma, boundary, registration, semantic loss et contrat restent des erreurs SDK explicites.

## Artifact and metric boundary

- noms `^[a-z0-9][a-z0-9._-]{0,63}$`;
- artefacts `cas://sha256/<64 lowercase hex>` seulement;
- métriques = `int|float` exacts, non-bool, finis, safe-range et non `-0.0`;
- aucune classe externe, path ou URL HTTP ne traverse comme artefact.

## Registry

```python
class AdapterRegistry:
    def register(self, adapter: object) -> None: ...
    def resolve(self, name: str) -> object: ...
    def identities(self) -> tuple[str, ...]: ...
```

Registration valide l’instance exacte du descriptor et les méthodes callables. Les accès de propriétés hostiles sont encapsulés. Noms ou identités dupliqués et adaptateurs incomplets échouent. `identities()` est trié.
