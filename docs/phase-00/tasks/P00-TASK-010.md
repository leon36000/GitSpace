### Descriptor

```python
@dataclass(frozen=True, slots=True)
class AdapterDescriptor:
    name: str
    version: str
    protocol_version: int
    implementation_digest: str

    @property
    def identity(self) -> str: ...
```

Invariants:

- `name` is lowercase ASCII and matches `^[a-z0-9]+(?:[._-][a-z0-9]+)*$`;
- `version` is non-empty printable ASCII;
- `protocol_version == 1`;
- `implementation_digest` matches `^sha256:[0-9a-f]{64}$`;
- `identity` is a deterministic string containing every field and no process-local identity.

### Canonical request

```python
@dataclass(frozen=True, slots=True)
class AdapterRequest:
    task: dict[str, JsonValue]
    agent: dict[str, JsonValue]
    seed: int
    extensions: dict[str, JsonValue]
```

The SDK constructs this canonical JSON object before invocation:

```json
{
  "version": 1,
  "task": {},
  "agent": {},
  "seed": 0,
  "extensions": {}
}
```

`task` validates against `urn:gitspace:schema:v1:eval-task-spec`; `agent` validates against `urn:gitspace:schema:v1:agent-configuration`. All eight schemas are loaded into one offline registry. Network resolution is forbidden.

### Adapter protocol

An adapter object exposes:

```python
descriptor: AdapterDescriptor

def prepare(self, request: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
def invoke(self, prepared: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
def collect(self, raw: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
```

`prepare` must return exactly:

```json
{
  "canonical_request": {},
  "framework_request": {},
  "extensions": {}
}
```

`canonical_request` must be exactly equal to the SDK request after JSON normalization. `invoke` receives the complete prepared object, including the canonical snapshot. A changed, missing or additional canonical field raises `SemanticLossError` **before** `invoke`.

`collect` must return exactly:

```json
{
  "status": "pass|fail|timeout|policy|infra",
  "summary": "bounded text",
  "artifacts": {"name": "cas://sha256/<64 lowercase hex>"},
  "metrics": {"name": 0},
  "extensions": {}
}
```

### Result

```python
class AdapterStatus(str, Enum):
    PASS = "pass"
    FAIL = "fail"
    TIMEOUT = "timeout"
    POLICY = "policy"
    INFRA = "infra"

@dataclass(frozen=True, slots=True)
class AdapterResult:
    adapter_identity: str
    status: AdapterStatus
    summary: str
    artifacts: dict[str, str]
    metrics: dict[str, int | float]
    extensions: dict[str, JsonValue]

    def to_json(self) -> dict[str, JsonValue]: ...
```

## Strict JSON boundary

Allowed values:

```text
null | bool | string | safe integer | finite float |
list[JsonValue] | dict[str, JsonValue]
```

The boundary rejects before crossing:

- bytes, tuple, set, dataclass, enum value not converted explicitly, arbitrary class or iterator;
- dictionary key that is not a string;
- `NaN`, `Infinity` and `-Infinity`;
- integer outside `[-9007199254740991, 9007199254740991]`;
- cyclic structure;
- excessive nesting beyond 64 levels;
- unknown core keys in request/prepared/result objects.

Every accepted tree is deep-copied. Adapter mutation cannot alter caller input, canonical request, prepared snapshot or returned result.

## Namespaced extensions

Every extension object uses the existing schema rule:

```regex
^[a-z0-9]+(?:[.-][a-z0-9-]+)+$
```

This applies to request, prepared and result extensions. A plain key such as `debug` is rejected.

## Runtime normalization

- normal collected payload controls PASS/FAIL/TIMEOUT/POLICY/INFRA;
- `AdapterTimeout` raised by `prepare`, `invoke` or `collect` returns TIMEOUT;
- `AdapterPolicyViolation` returns POLICY;
- any other external exception returns INFRA;
- normalized failure summary is single-line, control characters removed and at most 512 Unicode code points;
- schema/input errors, registration errors, semantic loss and boundary contract violations fail before external execution or return as explicit SDK errors; they are never disguised as agent failure.

## Artifact and metric boundary

- artifact names match `^[a-z0-9][a-z0-9._-]{0,63}$`;
- every artifact value is a canonical `cas://sha256/<64 lowercase hex>` URI;
- metric names use the same name rule;
- metric values are finite bool-excluding integers/floats inside the safe integer boundary;
- no external object or path crosses as an artifact.

## Registry

```python
class AdapterRegistry:
    def register(self, adapter: object) -> None: ...
    def resolve(self, name: str) -> object: ...
    def identities(self) -> tuple[str, ...]: ...
```

Registration validates descriptor type and the three required callable methods. Duplicate name or duplicate identity is rejected. `identities()` is sorted deterministically.

## Required contract tests

1. Valid task/config are schema-validated before `prepare`.
2. Invalid task or agent prevents every adapter method call.
3. A fake PASS adapter returns a JSON-only `AdapterResult` with deterministic identity.
4. Normal collected payloads cover the five statuses.
5. Timeout and policy exceptions normalize correctly.
6. Unexpected exceptions in prepare/invoke/collect normalize to INFRA with bounded text.
7. Caller objects and adapter-returned inputs cannot mutate canonical snapshots.
8. Changed or missing `canonical_request` raises `SemanticLossError` and invoke count stays zero.
9. Unknown prepared/result fields fail closed.
10. Non-JSON values, cycles, unsafe integers and non-finite numbers fail.
11. Unnamespaced extensions fail at request, prepare and result boundaries.
12. Artifact URI, artifact name, metric name and finite metric rules fail closed.
13. Registry rejects incomplete adapters, duplicate names and duplicate identities.
14. `to_json()` contains only JSON primitives and returns a fresh deep copy.
15. Identical input and fake adapter produce byte-equivalent JSON serialization with sorted keys.

## Required adversarial tests

- adapter mutates its request then returns the old snapshot;
- adapter keeps a reference and mutates after `execute_adapter` returns;
- `prepare` returns a custom Python object inside `framework_request`;
- `invoke` or `collect` returns tuple, bytes, set or object;
- result status is unknown or status casing differs;
- extension key attempts to overwrite a core field;
- artifact URI uses uppercase digest, relative path, HTTP URL or malformed CAS;
- metric is bool, `NaN`, infinity or unsafe integer;
- exception message contains newlines, NUL and more than 512 code points;
- duplicate registry entry uses different instance with same descriptor;
- schema resolver cannot fetch an unknown HTTP/URN reference;
- task/agent unknown core fields are rejected by the sovereign schemas.
