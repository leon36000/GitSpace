## Classification matrix

Précédence non compensable :

```text
POLICY → INFRA → TIMEOUT → PASS / FAIL
```

### POLICY

Seulement sur preuve GitSpace attribuable : montage/capability/path interdit, egress runtime observé, exposition secret/oracle, accès daemon depuis la tâche, ou mutation protégée. Le texte d'un message Harbor ne suffit jamais. `reward=None`.

### INFRA

Inclut : base absente/digest divergent; pull/build/start failure; `EnvironmentStartTimeoutError`; `AgentSetupTimeoutError`; `VerifierTimeoutError`; verifier crash; reward absente/malformée lorsque le verifier devait produire un résultat; exception Harbor inconnue; résultat/job/trial manquant ou multiple; CAS/digest/filesystem violation; timeout externe non attribuable à l'exécution agent; process group résiduel; cleanup incomplet; worker non qualifié; toute ambiguïté. `reward=None`.

### TIMEOUT

Uniquement si l'exception qualifiée exacte est `AgentTimeoutError`, le stage est `agent_execution`, environnement et setup ont terminé, et aucune gate POLICY/INFRA/intégrité/cleanup n'échoue. `reward=None`.

### PASS

Seulement si toutes les gates précédentes sont absentes, stages et verifier ont terminé, reward observée est exact `int(1)` non-bool, intégrité/CAS/cleanup sont vrais. `reward=1`.

### FAIL

Seulement si toutes les gates précédentes sont absentes, verifier fonctionnel a terminé avec assertion fonctionnelle incorrecte et reward observée exact `int(0)` non-bool, intégrité/CAS/cleanup vrais. `reward=0`.

Toute reward autre que `0` ou `1`, tout bool, toute reward manquante dans un chemin fonctionnel, et toute classe/stage inconnu deviennent `INFRA`.

La métrique `reward` n'est présente que pour PASS/FAIL; TIMEOUT/POLICY/INFRA n'ont aucune reward numérique synthétique.
