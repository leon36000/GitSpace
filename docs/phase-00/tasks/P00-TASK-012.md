## 10. Oracle exit code

Harbor 0.21.0 `OracleAgent` peut écrire `agent/exit-code.txt` sur retour non-zéro sans lever automatiquement une exception.

Le collecteur produit toujours `oracle_exit_status` sous JSON canonique :


Pour `run_purpose=qualification_oracle` :

- absence du raw avec phase agent terminée normalement est admise;
- s'il existe, le contenu doit être un entier exact et égal à `0` et doit correspondre à `oracle_exit_status`;
- toute autre valeur ou contradiction => `INFRA` + `task_invalid_candidate=true`;
- une reward `0` du vrai oracle n'est jamais `FAIL` : elle devient `INFRA` + `task_invalid_candidate=true`.

## 11. Classification

Précédence non compensable :

```text
POLICY → INFRA → TIMEOUT → terminal
```

### POLICY

Seulement sur preuve GitSpace attribuable : capability/path/montage interdit, egress runtime observé, exposition secret/oracle/daemon ou mutation protégée. Le texte d'un message Harbor ne suffit jamais.

### INFRA

Inclut : process Harbor non-zéro; worker/base/sidecar non qualifié; digest/image ID divergent; pull/build/start failure; `EnvironmentStartTimeoutError`; `AgentSetupTimeoutError`; `VerifierTimeoutError`; verifier crash; reward absente/malformée; exception inconnue ou stage inconnu; job/trial cardinalité incorrecte; CAS/filesystem violation; process résiduel; cleanup incomplet; oracle exit non-zéro; oracle reward `0`; toute ambiguïté.

### TIMEOUT

Uniquement exact `AgentTimeoutError` attribué au stage `agent_execution`, après setup/env valides et sans gate POLICY/INFRA. Reward = `None`.

### PASS

Toutes les gates sont vertes, process Harbor vaut `0`, reward JSON est exact `int(1)`, intégrité/CAS/cleanup vrais. Pour `qualification_oracle`, c'est le seul résultat fonctionnel terminal admissible.

### FAIL

Seulement pour `run_purpose=status_control` : process Harbor/fake process `0`, verifier fonctionnel, aucune gate supérieure, reward JSON exact `int(0)`, intégrité/CAS/cleanup vrais.

TIMEOUT/POLICY/INFRA n'ont jamais de reward numérique synthétique.
