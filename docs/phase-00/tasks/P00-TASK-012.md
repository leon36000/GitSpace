## 11. Classification

Précédence non compensable :

```text
POLICY → INFRA → TIMEOUT → terminal
```

### POLICY

Seulement sur preuve GitSpace attribuable : capability/path/montage interdit, egress runtime observé, exposition secret/oracle/daemon ou mutation protégée. Le texte d'un message Harbor ne suffit jamais.

### INFRA

Inclut : worker/base non qualifié; digest divergent; pull/build/start failure; `EnvironmentStartTimeoutError`; `AgentSetupTimeoutError`; `VerifierTimeoutError`; verifier crash; reward absente/malformée; exception inconnue; job/trial cardinalité incorrecte; CAS/filesystem violation; process résiduel; cleanup incomplet; oracle exit non-zéro; oracle reward `0`; toute ambiguïté.

### TIMEOUT

Uniquement exact `AgentTimeoutError` attribué au stage `agent_execution`, après setup/env valides et sans gate POLICY/INFRA. Reward = `None`.

### PASS

Toutes les gates sont vertes, reward JSON est exact `int(1)`, intégrité/CAS/cleanup vrais. Pour `qualification_oracle`, c'est le seul résultat fonctionnel terminal admissible.

### FAIL

Seulement pour `run_purpose=status_control` : verifier fonctionnel, aucune gate supérieure, reward JSON exact `int(0)`, intégrité/CAS/cleanup vrais.

TIMEOUT/POLICY/INFRA n'ont jamais de reward numérique synthétique.
